## Example: 用户仅提供仓库路径

**输入**: "帮我生成本周周报，仓库在 ~/Projects/codes/repo-a 和 ~/Projects/codes/repo-b"

该场景下 agent 会：
1. 使用默认模板（template.md）
2. 扫描两个仓库的 git log（默认周一至周五）
3. 仅输出 `.md` 文件到 workspace 根目录
4. 会询问是否需要 HTML 版本
